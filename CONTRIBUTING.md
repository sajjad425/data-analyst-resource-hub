# Contributing

Thanks for helping improve the Data Analyst Resource Hub!

## Before submitting
- Check whether the resource is already listed.
- Make sure the URL is correct and publicly accessible.
- Add the resource to the most relevant category.
- Describe the practical use case in one or two sentences.
- Avoid promotional claims that cannot be verified.
- Mention whether the resource is free, paid, or freemium only when you can verify it.
- Respect third-party licenses and do not commit copyrighted files without permission.

## Submit
Open an issue or pull request with the resource name, URL, category, and use case.
