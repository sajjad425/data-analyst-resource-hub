## 🌈 Colors & Visual Design

| Resource | Best use case |
|---|---|
| [BairesDev Color Palette App](https://www.bairesdev.com/tools/color-palette-app/) | Explore color palettes when choosing a consistent theme for a report or presentation. |
| [BairesDev AI Colors](https://www.bairesdev.com/tools/ai-colors) | Try AI-assisted color ideas for a dashboard theme. Review contrast and readability before applying a palette. |
| [Coolors Visualizer](https://coolors.co/visualizer/880d1e-dd2d4a-f26a8d-f49cbb-cbeef3) | Preview a palette in a visual context and judge whether colors work together. The supplied URL opens a particular palette; check the hex values before reusing them. |
| [Colormind](http://colormind.io/) | Generate color palette ideas using an AI-based palette tool. Useful for exploring alternatives, not a replacement for accessibility checks. |

**Dashboard color tips**
- Use a small, consistent palette rather than giving every chart a different color.
- Reserve a strong accent color for important KPIs, exceptions, or selected states.
- Check text/background contrast and avoid communicating status through color alone.
- Test the theme with labels, tooltips, slicers, and both positive and negative values.

## 🗂️ How to Use This Repository

1. **Choose the task.** For example, use SQLBI for a DAX concept or Coolors for a report theme.
2. **Open the resource.** Check its current features, terms, and pricing.
3. **Apply and adapt.** Make the result fit your data, business question, and audience.
4. **Validate.** Check calculations, readability, accessibility, and performance before sharing a report.
5. **Keep the list updated.** If a link changes or a better resource appears, submit an update.
